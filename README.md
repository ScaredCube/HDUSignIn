# HDU SignIn

**声明：本程序旨在不使用钉钉的情况下打开上课啦签到，仍然需要签到码和实时定位。使用本程序造成的一切影响由使用者本人承担**

主要是杭电钉加载实在是有点慢了，课室人多或者网不好的环境下经常打不开。故写了个单独的app用于优雅地上课签到。使用安卓原生开发保证app的小巧体积和流畅度，没有ios版本。

v2版本重构：从套壳webview改为原生UI，使用接口请求。启动时间更短，不用等待网页加载。鉴权使用账号密码，可以自动刷新凭据，减轻掉登录现象。新增支持多账号批量签到和定位管理功能。

## 使用说明

在 [releases](https://github.com/ScaredCube/HDUSignIn/releases) 页面下载最新版本。

在“账号”页面添加账号，使用学号和统一认证密码登录。正确登录后会显示您的姓名。之后在签到页面输入签到码即可签到。
